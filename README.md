# sudoku_notepad

A flutter application for creating, playing, and solving sudoku puzzles. This was my 4th year honours project at the University of glasgow, which earned an A5 grade. 

This application can provide hints for assisting the solving of puzzles, it also supports creating and playing a couple variations on the classic puzzle game; jigsaw and killer. There also exsists a solving algorith that looks at solving sudoku puzzles in a similar way that a human would approach a puzzle, opposed to the more traditional brute force method used in most other sudoku apps.

as the application is made with flutter it can be built for numerous platforms. To do so, simply follow the standard instructions for setting up, running, and building a flutter project.
